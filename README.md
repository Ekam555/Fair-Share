# Fair-Share
A precision bill-splitter web app built with vanilla HTML, CSS, and JavaScript that reconciles fractional cents to the exact penny and saves splits locally across page reloads

Key FeaturesExact Penny Reconciliation: Computes base shares and distributes remainder cents (+1¢) with visible verification that the shares match the total bill with zero discrepancy.   Occasion Presets & Party Stepper: Includes quick occasion chips (Dinner & Drinks, Weekend Trip, Shared Groceries, Team Lunch) and increment/decrement controls for party size.   Strict Input Validation: Blocks empty, zero, or negative bill totals and invalid headcounts with clear inline error alerts instead of displaying partial or inaccurate results.   Local Persistence & History: Automatically saves the active split and up to 6 recent splits in localStorage so calculations survive page reloads and can be reloaded with a click.   Shareable Summary & Print Support: Lets users copy a formatted text breakdown to the clipboard or print a clean receipt view.
